# صفحة فَذَكِّرْ

ملفات صفحة تحميل عربية RTL جاهزة للنشر على GitHub Pages.

## المستودع المقترح
`https://github.com/Ahmedmshaqer/fathakkir`

## خطوات النشر
1. أنشئ مستودعًا عامًا باسم `fathakkir` في حساب `Ahmedmshaqer`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع.
3. أنشئ Release جديدًا وارفع ملف APK باسم `Fathakkir.apk`.
4. فعّل GitHub Pages من Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

رابط تنزيل APK الذي تستخدمه الصفحة:
`https://github.com/Ahmedmshaqer/fathakkir/releases/latest/download/Fathakkir.apk`

إذا كان اسم المستودع غير متاح، اختر اسمًا آخر وأخبرني لتعديل رابط التحميل.
